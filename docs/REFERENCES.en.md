# References, provenance, and license records

[简体中文](REFERENCES.md) · [Project introduction](../README.en.md)

This page records third-party sources and their actual use in QingPing 0.4.1, checked on 2026-10-23. Links are pinned to the commits examined during research. Later upstream changes are not automatically incorporated. An upstream project's features, rule count, or device results do not establish equivalent coverage in QingPing.

A small set of built-in control identifiers is adapted from the **MIT-licensed rules in ganlinte/GKD-subscription**. QingPing implements its own matching conditions, action handling, risk checks, session budgets, and result confirmation. The other projects below informed comparisons of public behavior, Android APIs, or technical limits; their client engines, modules, models, and dependencies were not copied.

These are provenance entries, not a statement that only eight apps are supported or that every version of those apps has passed device tests. QingPing also uses general ad-specific labels and user-defined exact rules. Results depend on the target UI, exposed nodes, and system restrictions.

The original copyright and full MIT license are retained in [`app/src/main/assets/third_party_notices.txt`](../app/src/main/assets/third_party_notices.txt) and distributed as the same asset inside the APK. Redistributions of this rule information should retain those copyright and permission notices. QingPing uses its own rule format and does not directly accept GKD subscriptions.

## Research evidence and implementation limits

- Pinned code comparisons: [initial GitHub research](GITHUB_RESEARCH.md), [project comparison](PROJECT_COMPARISON.md), [splash catalog](SPLASH_CATALOG_RESEARCH.md), and [conditional SDK rules](SDK_RESEARCH_0.3.md). These Chinese historical notes include older behavior; the project introduction, source, and current verification record describe the current version.
- Node actions and privileged paths: [0.4 adaptation research](BILIBILI_RESEARCH_0.4.md). The [upstream consecutive-ad report](https://github.com/AIsouler/GKD_subscription/issues/1280), [GKD #1387](https://github.com/gkd-kit/gkd/issues/1387), and [GKD #1417](https://github.com/gkd-kit/gkd/issues/1417) provide problem context. Their reports, attachments, and upstream test results are not QingPing validation data.
- Features not adopted: [sensor-hook research](SENSOR_RESEARCH.md) and [image-fallback research](VISUAL_DETECTION_RESEARCH.md). Ordinary accessibility clicks do not block sensors or create a dismiss control that the target ad does not provide.

References and acknowledgements do not imply upstream authors' participation, review, or endorsement. No upstream license is used here to select an overall open-source license for QingPing. Terms for QingPing itself should come from an explicit, separate grant in this repository.
