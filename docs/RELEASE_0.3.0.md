# 清屏 0.3.0 交付说明

本版面向无 Root 的普通安卓设备，继续使用系统无障碍。安装包为本地安装 Debug 版，未发布商店。

## 本版变化

- 进入 APP 超过 15 秒后仍检查明确广告关闭控件；窗口/内容/点击事件可触发检查，空闲时约 1.5 秒重扫。锁屏、离开已选 APP 或暂停保护后停止对应检测。
- 成功关闭后重新待命。连续阶段共享次数预算，最终广告消失才确认一次；稳定普通内容后再次出现的广告可分别确认。
- 等待 disabled / 倒计时锁定按钮解锁，支持中央明确“关闭此条广告”等小型控件；有条件增加字节、快手、JAD、美数、Anythink 五个 SDK 关闭 ID。
- 支持小型可点击容器内拆开的“跳 / 过 / 广告”直接文字叶子。普通裸“跳过”仍限前 15 秒及独立广告证据，通用业务关闭不会自动处理。
- 精确规则可单独勾选“持续匹配”，用于较晚出现的弹窗与视频关闭。旧规则保留原时间窗口，不会因升级自动扩大匹配范围。
- 收紧下载、安装、支付、混合父节点、陈旧回调及不完整树的判断。拒绝/无效请求均有限次预算，不把请求提交当作成功。
- 来源统计、指定目标跳转后返回、后台/开机恢复提示及华为/vivo方向权限指南保留。

## 升级和启用

1. 使用本版 APK 覆盖安装，保持原签名与本地数据；不要先卸载或清除数据。
2. 打开清屏，重新阅读并同意版本 3 的持续前台检测用途。确认保护和目标 APP 的开关；升级不会自动启用新 APP。
3. 若系统无障碍未连接，进入系统设置手动打开；升级后系统未刷新服务配置时可关闭再打开一次。
4. “按钮可见但点不动”可在对应 APP 规则中单独允许模拟点击；默认关闭。精确规则还需勾选该条规则允许手势。
5. 先安装随附测试广告 APP 验证基础、35 秒弹窗、连续广告和业务误触负例。具体步骤见 [设备测试计划](DEVICE_TEST_PLAN.md)。

## 参考与验证

本轮读取了 GitHub 实际代码，见 [项目比较](PROJECT_COMPARISON.md)、[SDK 证据](SDK_RESEARCH_0.3.md) 和 [图像后备研究](VISUAL_DETECTION_RESEARCH.md)。本版没有接入截图、OCR、YOLO 或 VLM。

构建、逻辑测试、Lint 与签名结果见 [验证记录](VERIFICATION.md)。本轮未在模拟器、真实广告 SDK 或用户的华为/vivo手机验收；识别率、误触率、耗电和后台恢复仍待设备测试。没有可访问关闭控件或本来没有跳过功能时，清屏不会盲点屏幕或退出整个 APP 冒充成功；摇一摇仍按系统方向权限与跳转后返回的实际边界处理。
