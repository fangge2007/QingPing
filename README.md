# 清屏 QingPing

**简体中文** | [English](README.en.md)

清屏是一个无需 Root 的 Android 广告辅助关闭工具。在用户选定的应用位于解锁前台时，它识别系统允许读取的广告跳过或关闭控件，按规则请求点击，并观察页面结果。支持开屏、应用内弹窗和视频广告中可用的关闭按钮，以及指定广告跳转后的返回。

**0.4.1 · Android 8.0 / API 26 及以上 · 原生 Java · 本地运行**

[下载版本](https://github.com/fangge2007/QingPing/releases) · [各品牌完整操作指南](docs/PHONE_SETUP_GUIDE.md) · [参考项目与许可](docs/REFERENCES.md) · [验证记录](docs/VERIFICATION.md)

## 软件功能

| 功能 | 实际行为 |
| --- | --- |
| 逐应用管理 | 全局保护与每个来源应用分别开关；默认不处理任何应用。 |
| 广告辅助关闭 | 结合明确广告语义、完整资源 ID、页面、尺寸及上下文识别候选，等待倒计时后的控件真正可用。 |
| 延迟与连续广告 | 前台持续响应事件并低频观察后续页面；稳定恢复普通内容后可处理下一段广告。 |
| 精确规则 | 来源固定，页面、控件 ID、原文和无障碍描述等全部非空条件同时精确匹配；每条规则可单独设置持续匹配。 |
| 可选模拟点击 | 普通点击失败或受理后未关闭时，对已核实控件尝试中心手势；逐应用默认关闭，自建规则还需单独授权。 |
| 按钮诊断 | 手动开启 30 秒诊断，核对候选后创建规则；候选短时保存在内存，2 分钟后失效。 |
| 跳转后返回 | 一个来源配置一个明确目标包名，满足短时广告证据时，目标打开后尝试返回；可临时放行 10 分钟。 |
| 规则与统计 | 本地 JSON 导入预览、合并和导出；按来源、日期分别记录跳过及返回，可导出 CSV。 |
| 离线教程 | 应用内含 17 个可搜索、展开的通用主题，覆盖启用、排障、误触、后台及数据管理。 |

## 技术原理

使用 Android 公开的 `AccessibilityService`，没有注入广告应用进程，也不修改其 APK 或网络流量。

1. **限定范围。** 用户同意用途、手动授权无障碍后，仍需开启保护与来源应用。仅在屏幕解锁、所选应用前台时检查。
2. **读取可访问节点。** 响应窗口与内容事件，请求系统允许的非重要视图。优先查询已核实完整 ID，再有界遍历；常规每次最多 700 节点、24 层，排除输入框及其子树。
3. **组合条件。** 通用文案结合广告上下文、位置、尺寸；内置与自建规则另外约束来源、页面和 ID。自建规则的全部非空条件按原文同时匹配，不一律点击普通业务“关闭”。
4. **控制频率。** 进入后通常约每 250 毫秒密集检查，默认窗口 15 秒；之后约每 1.5 秒低频观察。持续扫描不扩大每条规则的范围：普通“跳过”仍受入口限制，精确规则默认 15 秒、可设 3–30 秒，可逐条允许持续匹配。
5. **复核后动作。** 优先 `ACTION_CLICK`。只有已授权且明确、安全的目标才可使用节点中心手势；受理后 2.5 秒未确认的升级还需同来源、同窗口、同位置。危险动作、危险点击祖先和不可用按钮会阻止动作。
6. **确认才统计。** 请求提交或手势回调不算成功；后续完整观察需确认广告控件及场景消失，或跳转后来源恢复。每段广告最多 4 次受理动作、8 次总请求；稳定清屏后恢复下一段机会。

实现入口：[界面](app/src/main/java/cn/qingping/app/MainActivity.java)、[无障碍适配层](app/src/main/java/cn/qingping/app/QingPingAccessibilityService.java)、[决策引擎](app/src/main/java/cn/qingping/app/engine/AdDecisionEngine.java)、[控件策略](app/src/main/java/cn/qingping/app/engine/AdControlPolicy.java)。详细参数见[实现说明](docs/IMPLEMENTATION_NOTES.md)。

### 能力边界

- 可见不等于可访问。图片、画布、受保护页面没有可读目标时，本版没有截图、OCR 或固定坐标后备。
- 不加速视频、不破解倒计时、不创造原本不存在的跳过按钮；奖励广告提前关闭可能无法领奖。
- 跳转返回发生在目标已打开之后，不能阻止首次启动，也不能撤销下载、提交或支付。
- 普通 APK 不能通用地禁用其他应用的运动传感器。部分系统有方向权限，需按本机实际选项调整。
- Android API 范围不等于所有机型、应用已验证；后台清理、应用升级和窗口变化都可能影响效果。

## 所有品牌通用的首次操作流程

1. **确认环境并安装。** 需要可运行 Android APK 和无障碍服务的 Android 8.0+ 环境。已有清屏时使用同签名覆盖安装，不要先卸载或清除数据。
2. **阅读用途并同意。** 首次打开阅读数据用途说明。0.4.0 已完成用途同意版本 4 的用户升级至 0.4.1 无需重复同意。
3. **选择来源应用。** 在“应用”逐个启用，在“配置规则”确认广告跳过选项。找不到桌面入口时，核实后手动添加包名。
4. **手动开启无障碍。** 从清屏进入系统设置并开启清屏。侧载出现受限设置时，核实来源后按本机提示处理，不关闭整体系统防护。
5. **开启保护并检查连接。** 分别确认系统无障碍已启用、服务实际已连接、保护总开关已开启；屏幕解锁后重新进入目标应用。
6. **按需检查后台。** 只有经常断连时检查清屏的电池、后台、自启动或睡眠限制。通知仅供可选开机提醒，不代替服务连接。
7. **先验证少量应用。** 分别检查广告和普通业务页面。模拟点击保持默认关闭；可靠候选普通点击无效时，再评估相应授权。

## 不同情况的应对策略

| 现象 | 建议顺序 |
| --- | --- |
| 所有应用突然失效 | 检查用途同意、总开关、来源开关、系统无障碍及实际连接，再检查锁屏和后台。 |
| 有按钮却无动作 | 运行检查后启动 30 秒诊断，核实候选再建规则；无节点时不能靠规则补出按钮。 |
| 点击受理但没关闭 | 仅为问题来源评估模拟点击，自建规则需同时允许该条规则手势。 |
| 晚到弹窗漏检 | 核对时间窗口，仅为核实控件启用持续匹配；动态倒计时原文可能让精确条件失配。 |
| 倒计时未结束 / 没有关闭功能 | 等待应用提供可用控件；需要观看领奖时先暂停来源保护。 |
| 正常内容被关闭 | 立即暂停，关来源模拟点击、删除问题规则，先验证普通页面再恢复。 |
| 主动链接被返回 | 清空该来源的目标包名，或设置中临时放行 10 分钟。 |
| 次数未增加 | 先看页面结果；请求失败、超时和不完整读取不算成功，次数不是网络拦截量。 |

## 权限与隐私

核心需要手动授权无障碍；通知仅供可选开机提醒。没有联网、截图、录屏、悬浮窗、VPN、Root、使用情况访问或读取全部安装包权限。设置、规则与统计保存在应用私有目录；普通识别不保存整页内容，诊断只暂存少量候选。卸载或清除数据会删除本机记录，导出文件由用户管理。完整说明见[权限与限制](docs/PERMISSIONS_AND_LIMITS.md)。
