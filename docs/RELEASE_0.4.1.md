# 清屏 0.4.1：通用使用教程与问题处理

本次把完整教程加入清屏，按使用步骤和问题现象组织，适用于不同 APP 与能够运行 Android APK 的手机。没有设置单一 APP 或手机品牌的专门教程；不同系统的菜单名称、授权入口和按钮行为仍以本机为准。

## 教程如何打开

- 用途同意页：“先阅读使用教程与问题处理”，可在授权前先了解用途和操作。
- 保护首页：“完整使用教程与问题处理”。
- 应用页：“使用教程：规则、点击与诊断”。
- 设置：“使用教程与问题处理”中的“打开完整教程”。

教程随 APK 保存在本机，可离线查看。可以搜索“点不动”“倒计时”“后台”“误触”等关键词，匹配主题会展开；也可清除搜索、逐项展开阅读。返回教程时刷新运行状态，阅读位置和展开状态在页面重建后保留。

顶部运行条件卡显示用途同意、服务实际连接、保护总开关和已选择 APP 数量，并提供前往系统无障碍、应用配置及运行/后台设置的入口。阅读教程或点击导航不会自动授权、启用保护、修改规则或开启模拟点击，具体设置仍需用户手动调整。

## 教程覆盖什么

- 首次启用、覆盖升级、系统更新后检查、选择来源 APP、应用分身及隔离空间、分屏与横竖屏等使用条件。
- 看得到按钮却不关闭、普通点击不生效、模拟点击双重授权、倒计时结束后关闭、延迟弹窗、连续阶段与再次出现的广告。
- 视频及奖励广告、摇一摇和外部跳转、重启或清理后断连、后台设置与耗电排查。
- 30 秒按钮诊断、精确规则的全部条件与时间范围、本地规则导入导出、统计含义、误触后的暂停和规则收窄、隐私与停止使用。
- 从少量 APP 开始验证，分别检查广告页面与普通业务页面；根据不同现象选择下一步。

策略明确区分服务未运行、规则未命中、控件不可用和系统没有暴露控件。可见但不可读的画面、仍禁止关闭或根本不提供跳过功能的广告，当前不能靠猜测坐标或放宽规则强行关闭。

## 升级与已有功能

版本号为 0.4.1，versionCode 为 5。本次只增加教程页面、现有设置导航及说明，不修改广告识别、点击后备、动作预算、统计确认、权限声明或数据用途。

用途同意版本继续为 4。已经完成版本 4 同意的用户本次无需重新同意；更早版本按软件显示的用途说明操作。使用原签名新版 APK 直接覆盖安装可保留本机设置、规则和统计，请勿为升级先卸载或清除数据。若系统无障碍开关已开启但服务未连接，可手动关闭再开启一次服务后检查。

当前仍无联网、截图、OCR、悬浮窗或 Root 功能。教程没有扩大可读取的数据或自动动作范围。
