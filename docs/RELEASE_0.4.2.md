# 清屏 0.4.2：许可、安全范围与发布构建

[English](RELEASE_0.4.2.en.md)

- 根目录加入 MIT 许可证，并随 APK 附带项目许可证；保留全部上游声明。
- 共用关键包名策略覆盖 UI、规则导入、持久配置和运行时动作。旧配置中的电话、紧急呼叫等关键应用也失效。
- 无障碍 XML 默认仅监听清屏，运行时按已授权来源和明确跳转目标更新事件包名，停用或撤销同意时收窄。
- 删除、清空、拨号、转账、卸载等中英文危险文案及资源名被拦截。手势及返回前再次核验动作授权与屏幕状态。
- 补 Android API 28/35 的服务层自动测试、JaCoCo 覆盖率报告和 GitHub Actions。
- 主安装包改为独立发布签名且不可调试的 release 包。**旧 0.4.1 调试包不能直接覆盖升级**，先阅读[迁移说明](RELEASE_BUILD.md)。

本次不扩充内置应用目录，也不声称提高真实广告覆盖率；诊断候选仍可一键预填精确规则。Robolectric 不等于真机或模拟器 UI 验收，真实覆盖率、耗电及误触率仍未测量。具体测试结果见 [验证记录](VERIFICATION.md)。
